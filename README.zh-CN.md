# DC04U 音频工具

一个 Chrome 扩展，包含两个实践项目：**音量跳变保护**与**十段参数 EQ／频响曲线比较**。使用地址为 [iBasso DC04U 官网控制台](https://devices.ibasso.cn/#/device/DC04U)。

## 项目一：音量跳变保护

在网页 WebHID 音量命令发送给设备之前检查。同一次操作向上增加 **超过30档**才拦截，恰好增加30档允许，下调不限，没有固定音量上限。连续拖动按整个手势累计判断；重连后重新等待真实设备音量报告建立基线。

它不测量声压、不保证听力安全，也不覆盖实体按键、其他程序、音源突响、增益变化或插拔爆音。

## 项目二：高级 EQ 与曲线比较

原始 A 与目标／参考 B 可独立选择、导入并交换。曲线在1kHz对齐；测量组和条件独立保留，缺失的装置信息明确标为未知。支持十段滤波器、频率／增益／Q精调、拖动、撤销重做、响应模拟、目标差值拟合以及预设导入导出。

编辑和拟合只改变草稿。实际应用需要读取目标槽、备份、核对量化参数后由用户手动确认；只有读回参数匹配才报告验证通过。

## 公开版数据

仓库附带3条自行生成的模拟曲线，明确标为 synthetic／demo，不代表真实耳机，也不是听音建议。原本机版本使用了公开的水月雨／HuiHiFi数据，但尚未确认其再分发许可，因此公开仓库保留代码和数据接口，不附带这些第三方数据副本。

可直接通过「导入」粘贴自己的两列频响数据；先指定原始A或目标B。至少需要10个不同频率的有效点，且覆盖1kHz。若持有可使用的完整本地曲线JSON／目录JSON，也可用 `scripts/use-local-library.mjs` 导入，见 [数据说明](data/SOURCES.md)。

## 无硬件预览

在仓库根目录运行：

```sh
python3 -m http.server 8769 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8769/preview.html`，点击「高级 EQ」。预览页不加载设备适配器，不连接或写入设备。

## 扩展安装与测试

在 Chrome 的 `chrome://extensions` 开启开发者模式，点击「加载已解压的扩展程序」并选择仓库根目录，然后重新加载官网。工具栏可查看保护状态；高级界面入口位于官网导航。

测试不需要硬件或第三方依赖：

```sh
node --test tests/*.test.cjs
```

测试使用模拟设备、模拟网页和合成数据，不播放声音。验证范围见 [VALIDATION.md](VALIDATION.md)。响应图是数学预测，并非耳机或固件的实测结果。

## 开发过程

项目使用AI编程助手辅助开发。项目所有者负责提出需求、定义交互规则、发现问题、评价修订并推动迭代；助手参与代码实现、公开资料核对和测试编写。项目运行不依赖本地大语言模型，曲线数据API也不是AI模型API。

与iBasso、水月雨、HuiHiFi无官方关联。尚未选择项目整体许可证；第三方数据与资料不附加新的许可。
